### 0.2 视觉方向整体换掉了（推翻第 3 节第 1 项）

原来定的是"跟随 SAChat 的 Material 风格：圆角卡片 + Material 3 间距"。
实际做下来换成了**深色优先的开发者工具风**（参考 linear.app / vercel.com 的克制感）：

- **深色是默认呈现**，浅色是配套的另一套（跟随系统，见 0.3）
- 靠 **1px 发丝边框**分割内容，**不用阴影、不用大圆角**（最大 12px）
- 所有数字、日期、版本号、标签都用**等宽字体**——这是"产品规格表"气质的来源
- **强调色只有一个**（紫蓝 `#8b8cf0`），只在"可点 / 选中 / 当前"处出现，占屏面积 < 5%
- 深色底色 `#0a0a0b` 刻意对齐了作者自己两个手表 App 的配色
  （腕上音符 `#1E1E1E`、腕能图库 `#1C1C1E`），网站和作品看起来是一套东西

**为什么推翻**：Material 那套"圆角卡片一路铺下去"的结果是每个项目长得一模一样，
读者分不清哪个是重点，而且卡片本身吃掉大量留白。
改成"规格表"（左列竖排参数、右列叙述与亮点、底部横滑截图）之后，
参数用等宽字竖排，比堆形容词可信得多。

**刻意不做的事**：不用「居中大标题 + 渐变文字 + 两个按钮」这个个人主页默认模板。

### 0.3 配色的执行方式变了（部分推翻第 3 节第 2 项 + 3.1）

| 项 | 原决定 | 实际执行 |
|---|---|---|
| 颜色数量 | 紫蓝**渐变** | 紫蓝**单色** `#8b8cf0`，不再做大面积渐变底 |
| 深浅色 | 跟随系统 | **没变**，仍跟随系统；但深色才是默认呈现 |
| 改色的位置 | 未明确 | 全部集中在 `src/index.css` 的 `@theme` 里 |
| `--radius-card` | 单值圆角 | 改成三档 `--radius-sm/md/lg`（4 / 8 / 12px） |

**颜色系统的机制（重要，改之前必须知道）**：
深色值定义在 `src/index.css` 的 `@theme` 块里，浅色值在文件下方 `html:not(.dark)` 里
**覆盖同一批变量名**。所以组件里几乎完全不写 `dark:` 前缀，**改配色只改 `index.css` 一个文件**。

> ⚠️ **坑**：颜色必须定义在 `@theme` 里。写到外面的 `:root` 会导致 Tailwind v4
> 不生成对应工具类，`bg-ground` 这类类名会**静默消失**（不报错、也不生效）。

紫蓝这个选择本身**没有被推翻**——第 3.1 节那段"制作者知情后仍选紫蓝、不要改回青色"
的记录依然有效，只是用法从"渐变"收紧成"单一强调色"。
（本条已于 2026-10-01 向作者说明，未提出异议。）
